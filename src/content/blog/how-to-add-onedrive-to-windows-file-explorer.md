OneDrive can sync your files between your Windows PC and the cloud. After you set up OneDrive, your synced files appear in File Explorer in a OneDrive folder.

This guide explains **how to add OneDrive to File Explorer** on Windows 10 and Windows 11. It also explains how to fix the common error: **OneDrive folder not showing in File Explorer**.

## Quick answer

To add OneDrive to File Explorer, install or open the OneDrive app, sign in with your Microsoft account, and complete OneDrive Setup. Accept the folder location or select a different location. After setup, open File Explorer and select the OneDrive folder.

On Windows 11, OneDrive is already installed on most PCs. Open the app and sign in to start the setup.

## What you need to check before you start

You need a Windows 10 or Windows 11 PC with an internet connection. You also need a Microsoft personal account, work account, or school account. If you do not have one, check Microsoft's instructions for [registering a Microsoft account](https://account.microsoft.com/account).

Make sure your operating system is activated and up to date. If you need help activating Windows, follow Microsoft's [Windows activation guidance](https://support.microsoft.com/en-us/windows/activation/activate-windows).

OneDrive is already installed on most current Windows systems. Check by searching for **OneDrive** on the taskbar or in the Start menu.

![Search for OneDrive or open it from the Start menu](/search-onedrive-start-menu.png)

If you do not see it, follow the installation steps below.

## How to install and add OneDrive to File Explorer

### Step 1: Download and install OneDrive manually

![Official download page for Microsoft OneDrive](/download-onedrive-manually.png)

Download OneDrive from the [official OneDrive download page](https://www.microsoft.com/microsoft-365/onedrive/download), then install the app. Open it from the Start menu or search for it in the Windows search box.

### Step 2: Sign in to OneDrive

When OneDrive Setup opens, enter your Microsoft account email address and select **Sign in**.

![Sign in to start using OneDrive](/onedrive-signin-page-login.png)

Enter your Microsoft account email and password if OneDrive asks for them. Complete any account security step that appears.

OneDrive supports personal accounts and work or school accounts. You can use more than one work or school account, but you can use only one personal OneDrive account on one PC.

### Step 3: Select your preferred OneDrive folder location

OneDrive Setup shows the location for your OneDrive folder. Select **Next** to use the default location.

To use a custom folder location, select **Change location** and choose a folder on your PC. You can also change the location later from OneDrive settings.

![Choose your preferred OneDrive folder](/select-onedrive-sync-folder.png)

Select the folder location before OneDrive starts the full sync. This is the best time to change the location.

### Step 4: Review Files On-Demand

OneDrive Setup explains Files On-Demand. This feature lets you see OneDrive files without downloading every file to your PC.

Online-only files use little local storage. Locally available files use space on your PC. Always available files remain on your PC for offline use.

Select **Next** after you read the information.

### Step 5: Open OneDrive in File Explorer

Open File Explorer. Select the File Explorer icon on the taskbar or press **Windows key + E**.

Look in the left panel for **OneDrive**. A personal account appears as **OneDrive – Personal**. A work or school account appears as **OneDrive – [CompanyName]**.

Select the OneDrive folder. Your synced files and folders appear there.

## How to sync OneDrive with File Explorer

OneDrive syncs changes between the OneDrive folder on your PC and the OneDrive website. A change on one side also appears on the other side after sync completes.

Use the OneDrive cloud icon to view sync status. A status icon beside a file also shows whether the file is online-only, locally available, or always available.

If you edit a synced file in File Explorer, OneDrive sends the change to the cloud when an internet connection is available. If you edit the file online, OneDrive sends the change to your PC.

## How to choose OneDrive folders for sync

You can choose which OneDrive folders sync to your PC. This option helps you control local storage.

1. Select the OneDrive cloud icon in the notification area.
2. Select the OneDrive **Help and Settings** icon.
3. Select **Settings**.
4. Open the **Account** tab.
5. Select **Choose folders**.
6. Clear the folders that you do not want to sync to this PC.
7. Select **OK**.

A folder that you clear is removed from this PC. The folder and its files remain available online. These folder choices apply only to the selected PC and account.

You cannot clear some important folders, such as Desktop, Documents, Pictures, and Personal Vault.

## OneDrive folder not showing in File Explorer: fixes

If the OneDrive folder is not showing in File Explorer, use these fixes in order.

### Make sure that OneDrive is running

Look in the Windows notification area for the OneDrive cloud icon. If you do not see the icon, select the arrow that shows hidden icons.

If the icon is not there, open the Start menu and start OneDrive. Wait for the app to load, then open File Explorer again.

Microsoft states that missing OneDrive icons can mean that OneDrive is not running.

### Make sure that you signed in to the correct account

Open OneDrive settings. Read the account name in the **Account** tab.

If the account is not correct, add the required account or sign out and sign in again. Work or school files can appear in a folder with the organization name.

### Open the OneDrive folder location directly

Open File Explorer. Enter the OneDrive folder path in the address bar if you know the folder location.

If you used the default location, look in your user folder for **OneDrive**. A work or school account can use a name such as **OneDrive – CompanyName**.

### Select the folders that must sync

Open OneDrive settings and select **Choose folders**. Make sure that the required folders are selected.

If a folder is not selected, it does not appear in the local OneDrive folder. The folder remains available on the OneDrive website.

### Check your internet connection and storage

Make sure that the PC has an internet connection. Then check your Microsoft storage quota.

If the storage quota is full, OneDrive cannot sync new files. Delete files that you do not need, or increase your storage capacity.

### Unlink and relink OneDrive

If the folder still does not appear, unlink the OneDrive account from settings. Then sign in again and complete OneDrive Setup. Microsoft lists unlinking and relinking as a fix for continued sync errors.

## Frequently asked questions

### Does OneDrive automatically appear in File Explorer?

OneDrive files appear in File Explorer after you install or open OneDrive, sign in, and complete setup. The files appear inside a OneDrive folder.

### Can I add OneDrive to File Explorer without syncing every file?

Yes. Files On-Demand lets you view online files without downloading every file. You can also choose which folders sync to the PC.

### Why does OneDrive show online files but not local files?

The required folder is not selected for sync, or the file is online-only. Open OneDrive settings and review **Choose folders**. Then download the file when you need local access.

### Where is the OneDrive folder in Windows?

The default folder is inside your Windows user folder. The name is usually **OneDrive**, **OneDrive – Personal**, or **OneDrive – CompanyName**.

### Does removing a folder from sync delete it from OneDrive?

No. Clearing a folder in **Choose folders** removes the folder from this PC. The folder remains available online.

## Final steps

After you add OneDrive to File Explorer, open the OneDrive folder and look for your files. Check the cloud icon if a file does not sync.

## Extra tips

### Activate OneDrive at PC startup

If you want OneDrive to run and sync your files automatically, make sure OneDrive is enabled in your PC's startup app list. You can turn it on or off from **Settings → Apps → Startup**.

This setting keeps OneDrive running in the background for automatic sync. If you still have problems, contact [Microsoft Support for OneDrive sync problems](https://support.microsoft.com/en-us/onedrive/fix-onedrive-sync-problems).
